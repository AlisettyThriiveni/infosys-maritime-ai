# Milestone 1 - User Authentication Module

## About
This milestone builds a user authentication system for the Infosys Springboard 7.0 internship project.

## Features
- Signup with validation and security question
- Login with JWT session tokens
- Forgot Password (Security Question and Email OTP)
- User Dashboard with Logout
- Admin Dashboard to view registered users

## Tech Stack
Python, Streamlit, JWT, SQLite, ngrok, Gmail SMTP, Google Colab

## How to Run
1. Open the notebook in Google Colab.
2. Add the required secrets in Colab Secrets.
3. Run all cells from top to bottom.
4. Open the ngrok URL printed in the last cell.
